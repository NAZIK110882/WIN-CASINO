# Winner Casino MVP 🎰🚀

Повноцінний навчальний командний вебпроєкт казино, розроблений для демонстрації повного циклу розробки сучасних вебдодатків: від проєктування реляційної бази даних та створення захищеного бекенд-API до інтерактивного фронтенду з плавною анімацією.

---

## 🛠 Стек технологій та інструменти
* **Фронтенд:** HTML5, CSS3, JavaScript (Vanilla JS, Fetch API, HTML5 Canvas API)
* **Бекенд:** PHP 8+ із використанням PDO (PHP Data Objects) для безпечних запитів до бази даних і захисту від SQL-ін'єкцій
* **База даних:** MySQL (реляційна структура, транзакції, збереження балансу та історії ігрових сесій)
* **Середовище локального розгортання:** XAMPP (Apache HTTP Server, MySQL)
* **Система контролю версій:** Git & GitHub (розподілена командна робота, робота з гілками, Pull Requests та Code Review)

## 🗄 Проєктування бази даних (MySQL)

### Архітектура таблиць:
* **`users`** — зберігає основні дані гравців: унікальний ідентифікатор (`id`), нікнейм (`username`), хешований пароль (`password_hash`) та актуальний баланс рахунку (`balance` типу DECIMAL для точності розрахунків).
* **`transactions`** *(рекомендовано для подальшого розширення)* — фіксує історію всіх поповнень, виграшів та програшів для детального аудиту.

## 👥 Командний Git Workflow та правила розробки
Проєкт створений для відпрацювання навичок колективної розробки. Щоб уникнути конфліктів у коді, дотримуйтеся таких інструкцій:
* **Ізоляція гілок:** Категорично заборонено робити прямі коміти чи пуші в головну гілку `main`. Для кожної нової задачі чи виправлення створюйте окрему гілку (наприклад, `git checkout -b feature/rocket-animation`).
* **Pull Requests (PR):** Після завершення написання коду створіть Pull Request на GitHub із описом ваших змін.
* **Code Review:** Злиття (`merge`) розробленого функціоналу в гілку `main` дозволене виключно після перевірки та схвалення (Approve) хоча б одним учасником вашої команди.
