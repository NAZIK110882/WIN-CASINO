## Stress test

Додайте файл `stress.json`. Відмітьте перший етап, де p95 перевищив 1 секунду або з'явилися помилки, та чи відновився сервіс під час спаду навантаження.

Попередній фактичний запуск користувача (2026-11-06): **400 VUs**, 96 365 запитів, 534.85 запитів/с; `http_req_failed` — **29.33%** (28 264 запити), avg — 148.38 ms, p95 — 157.25 ms, max — 27 s. Поріг k6 `<5%` помилок перевищено. Це агрегована підсумкова статистика: точний етап появи помилок і їхні HTTP-статуси в наданому виводі відсутні. JSON-файл цього запуску не зберігся через відмову в доступі до каталогу.

Другий запуск (2026-11-06, JSON збережено): **400 VUs**, 88 091 запит, 489.06 запитів/с; `http_req_failed` — **22.99%** (20 255 невдалих запитів), avg — 182.25 ms, p95 — 132.70 ms, max — 32.04 s. Поріг `<5%` також перевищено. Цей сценарійний файл ще не містив підсумкових порогів за окремими етапами; вони додані до наступного запуску.

Третій запуск зі stage thresholds (2026-11-06, JSON збережено): **400 VUs**, 81 139 запитів, 450.05 запитів/с; `http_req_failed` — **20.48%** (16 621 невдалий HTTP-запит), avg — 217.06 ms, p95 — 130.19 ms, max — 34.57 s. Поріг `<5%` перевищено, поріг загального p95 `<1 s` пройдено.
